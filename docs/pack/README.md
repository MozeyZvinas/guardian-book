Where the pack and later decisions disagree, `docs/decisions.md` wins (newer rulings, e.g. the
October 2026 reset). Flag any conflict in `docs/TASKS.md` rather than picking a side.

Keep confidential material (attorney correspondence, pricing, investor documents) out of
this folder if the repo is ever made public.
