# Guardian Book

A lifelong learning companion for South African learners — starting with high school
(Grades 8–12) and growing with them into study, work and life. One platform for the
learner, their guardian, their teacher and their school.

**Status:** project setup only. No application code yet.

## Where things live

| Path | What it is |
| --- | --- |
| `CLAUDE.md` | Project guide: what we're building, binding rules, engineering rules |
| `docs/decisions.md` | Decision log — what's decided, what's open |
| `docs/TASKS.md` | The build task list (shared state) |
| `docs/pack/` | Pre-development pack (product vision, PRD, tech spec, compliance…) |
| `prompts/` | Briefs for build sessions, run in order |

## Getting started

Nothing to install yet. The first build session runs `prompts/01-kickoff.md`, which
produces the architecture proposal and the first build plan for approval — still no code.
